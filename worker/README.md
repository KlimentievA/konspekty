# Синхронизация прогресса между устройствами

Что синхронизируется: отметки прочитанных глав и результаты тестов, избранное, дела, зачёты и план сессии, английский Насти, закладки и выделения, оформление и размер текста, место, где остановился.
Каждый профиль (Артём, Настя) хранится отдельно. Пока адрес хранилища не указан, сайт работает как раньше, всё хранится на устройстве.

## Включить (один раз, ~5 минут, бесплатно)

1. Зарегистрируйся на https://dash.cloudflare.com (нужна только почта).
2. Слева: Storage & Databases → KV → Create → имя `konspekty-sync`.
3. Слева: Compute (Workers) → Create → Start with Hello World → имя `konspekty-sync` → Deploy → Edit code.
   Удали всё, вставь содержимое `worker/sync-worker.js` → Deploy.
4. Worker → Settings → Bindings → Add → KV namespace. Имя переменной строго `KV`, namespace `konspekty-sync` → Deploy.
5. Скопируй адрес воркера (вида `https://konspekty-sync.<твой-ник>.workers.dev`) и пришли его в чат.
   Остальное (подставить адрес, собрать, выложить) делается за минуту.

## Как проверить
Открой `<адрес воркера>/p/artem`: должно показать `{}` (или данные после первых отметок).

## Что важно знать
- Данные не секретные (учебный прогресс), адрес воркера виден в коде сайта, поэтому запись не защищена паролем. Воркер принимает только профили artem и nastya, ограничивает размер и принимает записи только в виде «ключ → [значение, время]».
- Если одно и то же менять на двух устройствах без интернета, побеждает более поздняя правка по каждому ключу (например, по списку дел целиком).
- Бесплатного тарифа Cloudflare хватает с большим запасом (100 000 запросов в день).
