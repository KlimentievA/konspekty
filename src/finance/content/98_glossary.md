# Глоссарий
short: Термины и сокращения от A до Я

| Термин | Расшифровка | Значение |
|---|---|---|
| **ABB** | Accelerated Bookbuilding | Быстрая (за 1–2 дня) продажа крупного пакета акций крупным инвесторам, например фондам и банкам |
| **Accretion / Dilution** | | Насколько вырастет или упадёт прибыль на акцию (EPS) у покупателя после сделки |
| **APV** | Adjusted Present Value | Сначала считают стоимость компании так, будто долга нет, потом прибавляют сегодняшнюю стоимость (PV) налоговой экономии от процентов по долгу (налогового щита) |
| **ARPU** | Average Revenue Per User | Сколько выручки в среднем приносит один пользователь (телеком, интернет) |
| **ARR** | Annual Recurring Revenue | Выручка за год, которая повторяется из года в год, например по подписке (SaaS — программы по подписке) |
| **Beta (β)** | | Показывает, насколько сильно акция реагирует на движения рынка |
| **Bookrunner** | | Банк, который собирает заявки инвесторов при размещении акций или облигаций |
| **CAGR** | Compound Annual Growth Rate | Средний рост за год с учётом «процента на процент»: (Конец/Начало)^(1/n) − 1 |
| **CAPEX** | Capital Expenditures | Капитальные затраты: траты на покупку и обновление оборудования и других основных средств (ОС) |
| **CAPM** | Capital Asset Pricing Model | Модель, которая считает, какую доходность ждут от акции: Ke = Rf + β × ERP |
| **CET1** | Common Equity Tier 1 | Самый надёжный капитал банка: акции и нераспределённая прибыль (Базель III) |
| **CFO** | Cash Flow from Operations | Операционный денежный поток: деньги, которые компания получила от основной работы |
| **CFI** | Cash Flow from Investing | Инвестиционный поток: деньги на CAPEX, а также от покупки и продажи активов и компаний |
| **CFF** | Cash Flow from Financing | Финансовый поток: движение денег по долгу, дивидендам, байбэкам (выкупу своих акций) и выпуску новых акций |
| **CIM** | Confidential Information Memorandum | Подробное закрытое описание продаваемой компании для покупателей |
| **CIR** | Cost-to-Income Ratio | Какую долю доходов банка съедают его расходы: расходы / доходы |
| **CoR** | Cost of Risk | Цена кредитного риска: сколько денег банк отложил на возможные потери по кредитам (резервы / кредиты) |
| **CRP** | Country Risk Premium | Надбавка к доходности за то, что вложения в конкретной стране рискованнее |
| **D&A** | Depreciation & Amortization | Амортизация: постепенное списание стоимости основных средств (ОС) и нематериальных активов (НМА) в расходы |
| **DCF** | Discounted Cash Flow | Оценка компании по будущим денежным потокам, пересчитанным в сегодняшние деньги (дисконтированным) |
| **DCM** | Debt Capital Markets | Рынок, на котором компании занимают деньги, выпуская облигации |
| **DDM** | Dividend Discount Model | Оценка акции по будущим дивидендам, пересчитанным в сегодняшние деньги |
| **DPS** | Dividend Per Share | Сколько дивидендов приходится на одну акцию |
| **DSO / DIO / DPO** | Days Sales / Inventory / Payables Outstanding | За сколько дней в среднем оборачиваются: дебиторка (долги клиентов), запасы, кредиторка (долги перед поставщиками) |
| **Due diligence (DD)** | | Тщательная проверка компании перед сделкой: покупатель смотрит документы, финансы и риски |
| **EBIT** | Earnings Before Interest & Taxes | Операционная прибыль: заработок до вычета процентов и налогов |
| **EBITDA** | Earnings Before Interest, Taxes, D&A | Прибыль до вычета процентов, налогов и амортизации; грубо показывает, сколько компания зарабатывает на своей основной работе |
| **ECM** | Equity Capital Markets | Рынок, на котором компании привлекают деньги, продавая свои акции (IPO, SPO) |
| **EPS** | Earnings Per Share | Сколько чистой прибыли приходится на одну акцию |
| **ERP** | Equity Risk Premium | Дополнительная доходность, которую инвесторы требуют за то, что вкладываются в акции, а не в безрисковые бумаги |
| **EV** | Enterprise Value | Стоимость всего бизнеса целиком: капитал + чистый долг + … |
| **EVA** | Economic Value Added | Экономическая добавленная стоимость: (ROIC − WACC) × Инвестированный капитал |
| **FCF** | Free Cash Flow | Свободный денежный поток: деньги, которые остаются после операционных расходов, налогов и инвестиций |
| **FCFF** | Free Cash Flow to Firm | Свободный поток всем инвесторам (до долга), то есть и кредиторам, и акционерам: EBIT×(1−t) + D&A − CAPEX − ΔNWC. Дисконтируется по WACC |
| **FCFE** | Free Cash Flow to Equity | Свободный поток только акционерам (после долга). Дисконтируется по Ke |
| **FFO** | Funds From Operations | Денежная прибыль REIT (фонда, который владеет недвижимостью) |
| **Free float** | | Какая доля акций свободно торгуется на бирже |
| **Goodwill** | | Переплата при покупке компании: на сколько цена покупки больше справедливой стоимости её чистых активов |
| **Greenshoe** | | Право организатора размещения продать дополнительные акции (до 15%), чтобы удерживать цену на стабильном уровне |
| **ICR** | Interest Coverage Ratio | Покрытие процентов: во сколько раз прибыль больше процентов (EBIT / проценты) |
| **IFRS / МСФО** | International Financial Reporting Standards | Международные правила составления финансовой отчётности |
| **IPO** | Initial Public Offering | Первичное публичное размещение: компания впервые продаёт свои акции на бирже |
| **SPO** | Secondary Public Offering | Повторная продажа акций компании, которая уже торгуется на бирже |
| **IRR** | Internal Rate of Return | Внутренняя норма доходности: годовая доходность проекта, то есть ставка, при которой NPV = 0 |
| **LBO** | Leveraged Buyout | Покупка компании в основном на заёмные деньги |
| **Lock-up** | | Запрет продавать свои акции после IPO (обычно 180 дней) |
| **LTM / TTM / NTM** | Last / Trailing / Next Twelve Months | Последние 12 месяцев (LTM, TTM) или следующие 12 месяцев (NTM) |
| **M&A** | Mergers & Acquisitions | Слияния и поглощения компаний |
| **MAC** | Material Adverse Change | Оговорка в договоре о существенном негативном изменении: если оно случится, покупатель может отказаться от сделки |
| **MoM / MOIC** | Multiple of Money / Multiple on Invested Capital | Во сколько раз выросли вложенные деньги |
| **MVA** | Market Value Added | Рыночная стоимость компании минус вложенный в неё капитал |
| **NAV** | Net Asset Value | Стоимость чистых активов: что останется, если из имущества вычесть долги |
| **NBO / BO** | (Non-) Binding Offer | Предложение о покупке: необязывающее (NBO) или обязывающее (BO) |
| **NCI** | Non-Controlling Interest | Доли меньшинства: часть дочерней компании, которая принадлежит другим владельцам, а не материнской компании |
| **NDA** | Non-Disclosure Agreement | Соглашение о конфиденциальности: стороны обещают не раскрывать полученные сведения |
| **Net Debt** | | Чистый долг = Долг − Денежные средства |
| **NIM** | Net Interest Margin | Чистая процентная маржа банка: «наценка» банка на разнице между ставками по кредитам и по депозитам |
| **NOPAT** | Net Operating Profit After Tax | Операционная прибыль после налога: EBIT × (1 − t) |
| **NPL** | Non-Performing Loans | Проблемные кредиты: те, по которым заёмщик перестал платить |
| **NPV** | Net Present Value | Чистая приведённая стоимость: сегодняшняя стоимость будущих денег минус вложения |
| **NWC** | Net Working Capital | Чистый оборотный капитал: деньги, которые «застряли» в повседневной работе (запасы и долги клиентов минус долги перед поставщиками) |
| **OPEX** | Operating Expenses | Операционные расходы: траты на повседневную работу |
| **P/E** | Price to Earnings | Капитализация / чистая прибыль (= цена / EPS). Показывает, за сколько лет прибыли окупится покупка компании |
| **P/B** | Price to Book | Капитализация / балансовый собственный капитал. Главный мультипликатор для банков |
| **P/S** | Price to Sales | Капитализация / выручка. Подходит для убыточных и быстрорастущих компаний |
| **Payback** | | Срок окупаемости: за сколько времени вложения вернутся |
| **PE (Private Equity)** | | Фонды прямых инвестиций: они покупают компании, чтобы развить их и потом продать дороже |
| **PEG** | P/E to Growth | P/E, делённый на темп роста EPS |
| **PI** | Profitability Index | Индекс прибыльности: PV потоков / инвестиции |
| **PIK** | Payment-in-Kind | Проценты, которые не выплачивают, а прибавляют к сумме долга |
| **RAB** | Regulatory Asset Base | Регулируемая база активов: стоимость имущества (сетей, инфраструктуры), от которой государство считает допустимую прибыль |
| **Rf** | Risk-free rate | Безрисковая ставка: доходность вложений, в которых риск практически отсутствует |
| **RI** | Residual Income | Остаточная прибыль: ЧП − Ke × Капитал (то, что осталось после того, как акционерам заплатили «положенную» доходность) |
| **ROE** | Return on Equity | Чистая прибыль / собственный капитал. Показывает доходность денег акционеров |
| **ROA** | Return on Assets | Чистая прибыль / активы. Для банков нормой считается 1–3% |
| **ROIC** | Return on Invested Capital | NOPAT / инвестированный капитал. Если ROIC > WACC, компания создаёт стоимость |
| **ROCE** | Return on Capital Employed | EBIT / (активы − краткосрочные обязательства) |
| **SG&A** | Selling, General & Administrative | Коммерческие и управленческие расходы: на продажи и на содержание офиса и управления |
| **SOTP** | Sum of the Parts | Оценка по частям: каждую часть бизнеса оценивают отдельно и складывают |
| **SPA** | Share Purchase Agreement | Договор купли-продажи акций |
| **Synergies** | | Синергии: дополнительная стоимость, которая появляется от объединения компаний |
| **Teaser** | | Короткое анонимное описание компании, которое рассылают потенциальным покупателям |
| **TV** | Terminal Value | Терминальная (постпрогнозная) стоимость: стоимость бизнеса за пределами прогнозного периода |
| **TSR** | Total Shareholder Return | Полная доходность акционера: рост цены акции + дивиденды |
| **VDR** | Virtual Data Room | Виртуальная комната данных: закрытое онлайн-хранилище документов для due diligence |
| **WACC** | Weighted Average Cost of Capital | Средневзвешенная стоимость капитала: средняя цена всех денег компании, и заёмных, и собственных |
| **YTM** | Yield to Maturity | Доходность к погашению: сколько заработает покупатель облигации, если продержит её до конца срока |
| **Accrued interest** | | См. НКД |
| **Basis point (б.п.)** | | Базисный пункт = 0,01%. 50 б.п. = 0,5 п.п. |
| **Capital rationing** | | Ограниченный бюджет на инвестиции: проекты выстраивают по PI и берут лучшие, пока деньги не кончатся |
| **Comps** | Comparable companies | Таблица похожих компаний и их мультипликаторов |
| **Covenant** | | Условие кредитного договора, которое заёмщик обязан соблюдать (например, ND/EBITDA ≤ 3×) |
| **Credit spread** | | Кредитный спред: доходность облигации компании минус доходность госбумаги того же срока |
| **Earn-out** | | Часть цены сделки, которую платят позже, если компания достигнет оговорённых результатов |
| **Equity Value** | | Стоимость акционерного капитала (для публичной компании — капитализация) |
| **FDV** | Fully Diluted Valuation | Капитализация криптотокена, если посчитать по максимальному числу токенов, которое можно выпустить |
| **G-spread** | | Спред доходности облигации к кривой госбумаг (КБД) на том же сроке |
| **Hurdle rate** | | Минимальная доходность, которую должен дать проект, чтобы в него стоило вкладываться (часто WACC + премия) |
| **Leverage** | | Финансовый рычаг: использование долга. Часто его измеряют как ND/EBITDA |
| **Locked box** | | Способ определить цену сделки: её фиксируют по балансу на прошлую дату, и дальше цена не пересчитывается |
| **MOIC** | Multiple on Invested Capital | Во сколько раз вырос вложенный капитал фонда |
| **Pitchbook** | | Презентация банка для клиента: идея сделки, оценка, аналоги |
| **Precedent transactions** | | Сделки-аналоги: мультипликаторы, по которым прошли прошлые сделки M&A |
| **Run-rate** | | Годовой показатель, который получают, умножив результат последнего периода (квартал × 4) |
| **Sell-side / Buy-side** | | Консультирование продавца (sell-side) или покупателя (buy-side) в сделке; также так называют брокеров (sell-side) и фонды (buy-side) |
| **Tender offer** | | Публичное предложение ко всем акционерам: продайте нам свои акции по этой цене |
| **Waterfall** | | Очерёдность выплат кредиторам и акционерам, когда делят деньги или компания банкротится |
| **WC peg** | | Нормальный уровень оборотного капитала, от которого корректируют цену сделки |
| **Дефолт** | | Неисполнение обязательств по долгу: компания не выплатила купон или не погасила долг |
| **Квал** | Квалифицированный инвестор | Особый статус, который открывает доступ к сложным инструментам. Его присваивают по критериям ЦБ (размер активов, опыт сделок, образование и др.) |
| **ПДН** | Показатель долговой нагрузки | Какая доля доходов заёмщика уходит на платежи по кредитам (его регулирует ЦБ) |
| **КБД** | Кривая бескупонной доходности | Кривая доходности ОФЗ (ЦБ, Мосбиржа): показывает, какую доходность дают госбумаги на разные сроки |
| **НКД** | Накопленный купонный доход | Часть купона, которая набежала с последней выплаты до сегодняшнего дня |
| **ОФЗ** | Облигации федерального займа | Облигации, которые выпускает государство РФ |
| **РСБУ** | Российские стандарты бухучёта | |
| **ФСО** | Федеральные стандарты оценки | Стандарты оценочной деятельности РФ |
| **Н1** | Норматив достаточности капитала | Требование ЦБ к капиталу банков |
| **Break fee** | Termination fee | Неустойка, которую платит цель, если выходит из сделки ради другого предложения |
| **Club deal** | | Кредит нескольких банков без широкой синдикации (то есть без привлечения множества участников) |
| **Combined ratio** | | (Убытки + расходы) / премии у страховщика. Если меньше 100%, страхование само по себе прибыльно |
| **Cost of risk** | CoR | Резервы под кредитные потери / средний кредитный портфель |
| **DSCR** | Debt Service Coverage Ratio | Денежный поток для обслуживания долга / (проценты + плановое погашение). Показывает, во сколько раз заработок больше платежей по долгу |
| **Fulcrum security** | | Уровень долга, на котором заканчивается стоимость бизнеса. Его держатели получают контроль при реструктуризации |
| **Haircut** | | Списание части долга: кредитор получает меньше номинала |
| **LGD** | Loss Given Default | Доля потерь при дефолте = 1 − recovery rate |
| **LLCR** | Loan Life Cover Ratio | NPV потоков проекта за срок кредита / остаток долга |
| **MAC / MAE** | Material Adverse Change / Effect | Условие, по которому покупатель может отказаться от сделки, если случится существенное негативное событие |
| **Poison pill** | Shareholder rights plan | Защита цели от поглощения: если покупатель набрал акций больше порога, остальные акционеры получают право купить акции со скидкой |
| **Recovery rate** | | Доля номинала долга, которую кредитор вернёт при дефолте |
| **RWA** | Risk-Weighted Assets | Активы банка, взвешенные на риск (чем рискованнее актив, тем больше вес). На них делят капитал при расчёте коэффициентов капитала |
| **Squeeze-out** | | Принудительный выкуп оставшихся акций покупателем с долей более 95% |
| **Term Loan A / B** | TLA / TLB | Старший кредит. Кредит A амортизируется (гасится частями) и обычно выдан банками. Кредит B почти не амортизируется и выдан инвесторами |
