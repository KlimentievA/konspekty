# Глоссарий
short: Термины и сокращения от A до Я

| Термин | Расшифровка | Значение |
|---|---|---|
| **ABB** | Accelerated Bookbuilding | Быстрое (1–2 дня) размещение пакета акций среди институциональных инвесторов |
| **Accretion / Dilution** | | Рост / снижение EPS покупателя после сделки |
| **APV** | Adjusted Present Value | Стоимость без долга + PV налогового щита |
| **ARPU** | Average Revenue Per User | Средняя выручка на пользователя (телеком, интернет) |
| **ARR** | Annual Recurring Revenue | Годовая повторяющаяся выручка (SaaS) |
| **Beta (β)** | | Чувствительность акции к рынку |
| **Bookrunner** | | Банк, ведущий книгу заявок при размещении |
| **CAGR** | Compound Annual Growth Rate | Среднегодовой темп роста: (Конец/Начало)^(1/n) − 1 |
| **CAPEX** | Capital Expenditures | Капитальные затраты (покупка ОС) |
| **CAPM** | Capital Asset Pricing Model | Модель: Ke = Rf + β × ERP |
| **CET1** | Common Equity Tier 1 | Базовый капитал банка (Базель III) |
| **CFO / CFI / CFF** | Cash Flow from Operating / Investing / Financing | Разделы отчёта о движении денег |
| **CIM** | Confidential Information Memorandum | Подробный меморандум о продаваемой компании |
| **CIR** | Cost-to-Income Ratio | Расходы / доходы банка |
| **CoR** | Cost of Risk | Стоимость риска (резервы / кредиты) |
| **CRP** | Country Risk Premium | Страновая премия за риск |
| **D&A** | Depreciation & Amortization | Амортизация ОС и НМА |
| **DCF** | Discounted Cash Flow | Оценка по дисконтированным денежным потокам |
| **DCM** | Debt Capital Markets | Долговой рынок капитала |
| **DDM** | Dividend Discount Model | Модель дисконтирования дивидендов |
| **DPS** | Dividend Per Share | Дивиденд на акцию |
| **DSO / DIO / DPO** | Days Sales / Inventory / Payables Outstanding | Дни оборота дебиторки / запасов / кредиторки |
| **Due diligence (DD)** | | Комплексная проверка компании перед сделкой |
| **EBIT** | Earnings Before Interest & Taxes | Операционная прибыль до процентов и налогов |
| **EBITDA** | Earnings Before Interest, Taxes, D&A | Прибыль до процентов, налогов и амортизации |
| **ECM** | Equity Capital Markets | Рынок акционерного капитала (IPO, SPO) |
| **EPS** | Earnings Per Share | Прибыль на акцию |
| **ERP** | Equity Risk Premium | Премия за риск вложений в акции |
| **EV** | Enterprise Value | Стоимость бизнеса (капитал + чистый долг + …) |
| **EVA** | Economic Value Added | (ROIC − WACC) × Инвестированный капитал |
| **FCF / FCFF / FCFE** | Free Cash Flow (to Firm / to Equity) | Свободный денежный поток (всем инвесторам / акционерам) |
| **FFO** | Funds From Operations | Денежная прибыль REIT |
| **Free float** | | Доля акций в свободном обращении |
| **Goodwill** | | Превышение цены покупки над справедливой стоимостью чистых активов |
| **Greenshoe** | | Опцион организатора на доп. размещение (до 15%) для стабилизации цены |
| **ICR** | Interest Coverage Ratio | Покрытие процентов (EBIT / проценты) |
| **IFRS / МСФО** | International Financial Reporting Standards | Международные стандарты отчётности |
| **IPO / SPO** | Initial / Secondary Public Offering | Первичное / вторичное публичное размещение |
| **IRR** | Internal Rate of Return | Внутренняя норма доходности (ставка, при которой NPV = 0) |
| **LBO** | Leveraged Buyout | Покупка компании преимущественно за счёт долга |
| **Lock-up** | | Запрет продавать акции после IPO (обычно 180 дней) |
| **LTM / TTM / NTM** | Last / Trailing / Next Twelve Months | Последние / следующие 12 месяцев |
| **M&A** | Mergers & Acquisitions | Слияния и поглощения |
| **MAC** | Material Adverse Change | Оговорка о существенном негативном изменении |
| **MoM / MOIC** | Multiple of Money / Multiple on Invested Capital | Во сколько раз выросли вложения |
| **MVA** | Market Value Added | Рыночная стоимость − инвестированный капитал |
| **NAV** | Net Asset Value | Стоимость чистых активов |
| **NBO / BO** | (Non-) Binding Offer | (Не)обязывающее предложение о покупке |
| **NCI** | Non-Controlling Interest | Доли меньшинства |
| **NDA** | Non-Disclosure Agreement | Соглашение о конфиденциальности |
| **Net Debt** | | Чистый долг = Долг − Денежные средства |
| **NIM** | Net Interest Margin | Чистая процентная маржа банка |
| **NOPAT** | Net Operating Profit After Tax | EBIT × (1 − t) |
| **NPL** | Non-Performing Loans | Проблемные кредиты |
| **NPV** | Net Present Value | Чистая приведённая стоимость |
| **NWC** | Net Working Capital | Чистый оборотный капитал |
| **OPEX** | Operating Expenses | Операционные расходы |
| **P/B, P/E, P/S** | Price to Book / Earnings / Sales | Мультипликаторы капитализации |
| **Payback** | | Срок окупаемости |
| **PE (Private Equity)** | | Фонды прямых инвестиций |
| **PEG** | P/E to Growth | P/E, делённый на темп роста EPS |
| **PI** | Profitability Index | PV потоков / инвестиции |
| **PIK** | Payment-in-Kind | Проценты, которые капитализируются в долг вместо выплаты |
| **RAB** | Regulatory Asset Base | Регулируемая база активов (сети, инфраструктура) |
| **Rf** | Risk-free rate | Безрисковая ставка |
| **RI** | Residual Income | Остаточная прибыль: ЧП − Ke × Капитал |
| **ROA / ROE / ROIC / ROCE** | Return on Assets / Equity / Invested / Capital Employed | Показатели рентабельности |
| **SG&A** | Selling, General & Administrative | Коммерческие и управленческие расходы |
| **SOTP** | Sum of the Parts | Оценка по частям |
| **SPA** | Share Purchase Agreement | Договор купли-продажи акций |
| **Synergies** | | Синергии: доп. стоимость от объединения |
| **Teaser** | | Короткое анонимное описание компании для покупателей |
| **TV** | Terminal Value | Терминальная (постпрогнозная) стоимость |
| **TSR** | Total Shareholder Return | Полная доходность акционера (рост цены + дивиденды) |
| **VDR** | Virtual Data Room | Виртуальная комната данных для due diligence |
| **WACC** | Weighted Average Cost of Capital | Средневзвешенная стоимость капитала |
| **YTM** | Yield to Maturity | Доходность к погашению |
| **КБД** | Кривая бескупонной доходности | Кривая доходности ОФЗ (ЦБ, Мосбиржа) |
| **НКД** | Накопленный купонный доход | Часть купона, накопленная с последней выплаты |
| **ОФЗ** | Облигации федерального займа | Гособлигации РФ |
| **РСБУ** | Российские стандарты бухучёта | |
| **ФСО** | Федеральные стандарты оценки | Стандарты оценочной деятельности РФ |
| **Н1** | Норматив достаточности капитала | Требование ЦБ к капиталу банков |
