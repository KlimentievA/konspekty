# Деньги во времени: NPV, IRR, окупаемость
short: Дисконтирование, аннуитеты, NPV, IRR, payback

> **Суть.** Рубль сегодня дороже рубля завтра: его можно положить под процент, а инфляция и риск съедают будущие деньги. Поэтому будущие потоки **дисконтируют**: приводят к сегодняшнему дню по ставке r.

## Базовые формулы

```f
FV = PV × (1 + r)^n                 — будущая стоимость
PV = FV / (1 + r)^n                 — приведённая (текущая) стоимость
DF = 1 / (1 + r)^t                  — коэффициент дисконтирования
```

**Пример.** 1 000 ₽ через 3 года при r = 15%: PV = 1 000 / 1,15³ = 1 000 / 1,521 = **657 ₽**.

### Аннуитет и перпетуитет

```f
Аннуитет (C каждый год, n лет):   PV = C × [1 − (1 + r)^−n] / r
Перпетуитет (вечно, без роста):   PV = C / r
Перпетуитет с ростом g (Гордон):  PV = C₁ / (r − g)       (только если r > g!)
```

Важно: в формуле Гордона в числителе стоит поток **следующего** года: C₁ = C₀ × (1 + g).

### Номинальные и реальные ставки (Фишер)

```f
(1 + r_ном) = (1 + r_реал) × (1 + π)
r_реал ≈ r_ном − π                   (для небольших значений)
```

Правило: **номинальные потоки дисконтируй по номинальной ставке, реальные по реальной**. Смешивать нельзя.

### Правило 72

Деньги удваиваются примерно за **72 / (ставка в %)** лет. При 12% это ~6 лет, при 16% ~4,5 года.

## Критерии инвестиционных решений

### NPV — чистая приведённая стоимость

```f
NPV = Σ CFₜ / (1 + r)^t  − I₀        (t = 1…n)
```

- **NPV > 0** → проект создаёт стоимость (принимаем).
- **NPV < 0** → разрушает стоимость.
- NPV показывает, **на сколько рублей сегодня** проект делает компанию дороже.
- NPV **аддитивен**: NPV(A + B) = NPV(A) + NPV(B). Поэтому это главный критерий.

### IRR — внутренняя норма доходности

Ставка, при которой NPV = 0:
```f
0 = Σ CFₜ / (1 + IRR)^t  − I₀
```

- **IRR > WACC** → проект выгоден.
- Считается подбором (в Excel `ВСД` / `IRR`, для неравных дат `ЧИСТВНДОХ` / `XIRR`).

**Недостатки IRR (любят спрашивать):**
1. **Несколько IRR**, если знак потоков меняется больше одного раза (например, затраты на рекультивацию в конце проекта в горной добыче).
2. **Масштаб**: IRR 50% на 1 млн хуже, чем IRR 20% на 1 млрд. При выборе из взаимоисключающих проектов смотри на NPV.
3. **Предположение о реинвестировании** промежуточных потоков по ставке IRR (нереалистично при высоких IRR). Решение — **MIRR**:
```f
MIRR = (FV положительных потоков по ставке реинвестирования / PV затрат по ставке финансирования)^(1/n) − 1
```

### Срок окупаемости (Payback)

- **Простой**: через сколько лет накопленный поток станет ≥ 0.
- **Дисконтированный**: то же, но по дисконтированным потокам (всегда дольше простого).
```f
Payback = (последний год с отрицательной накопленной суммой) + |накопленная сумма в этом году| / поток следующего года
```
Минус: игнорирует всё, что после окупаемости.

### PI — индекс прибыльности

```f
PI = PV будущих потоков / I₀          (PI > 1 ⇔ NPV > 0)
```
Полезен при **ограниченном бюджете** (capital rationing): ранжируй проекты по PI.

## Mid-year convention (дисконтирование середины года)

Потоки приходят **в течение года**, а не 31 декабря. Поэтому период дисконтирования берут **t − 0,5**: 0,5; 1,5; 2,5… Это повышает стоимость примерно на (1 + r)^0,5. В твоей домашке по «Project Black» это использовалось именно так.

## Пример расчёта (на пальцах)

Инвестиция 1 000, потоки 300 / 400 / 500 / 300, ставка 12%.

| Год | Поток | DF = 1/1,12^t | PV |
|---|---|---|---|
| 0 | −1 000 | 1,000 | −1 000 |
| 1 | 300 | 0,893 | 268 |
| 2 | 400 | 0,797 | 319 |
| 3 | 500 | 0,712 | 356 |
| 4 | 300 | 0,636 | 191 |
| | | **NPV** | **+133** |

IRR ≈ 18,0% (> 12% → принимаем). Простой payback: после 2-го года накоплено −300, в 3-й год +500 → **2,6 года**.
