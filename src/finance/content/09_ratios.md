# Финансовые коэффициенты
short: ROE, ROIC, DuPont, долговая нагрузка, ликвидность

> **Суть.** Коэффициенты помогают быстро понять, **насколько бизнес прибылен, устойчив и эффективен**, и сравнить его с аналогами.

## Рентабельность

| Показатель | Формула | Смысл |
|---|---|---|
| **ROE** | Чистая прибыль / Средний собств. капитал | Доходность акционеров |
| **ROA** | Чистая прибыль / Средние активы | Эффективность всех активов (для банков норма 1–3%) |
| **ROIC** | NOPAT / Инвестированный капитал | Доходность бизнеса на весь вложенный капитал. **ROIC > WACC → создаётся стоимость** |
| **ROCE** | EBIT / (Активы − Краткоср. обязательства) | Похоже на ROIC, до налога |

### Формула DuPont

```f
ROE = Чистая маржа × Оборачиваемость активов × Финансовый рычаг
    = (ЧП / Выручка) × (Выручка / Активы) × (Активы / Капитал)
```
Показывает, **откуда** высокий ROE: от маржи (люкс), оборачиваемости (ритейл) или долга (банки).

## Долговая нагрузка

| Показатель | Формула | Ориентир |
|---|---|---|
| **Net Debt / EBITDA** | (Долг − Кэш) / EBITDA | < 1,5× комфортно; 2–3× умеренно; > 3,5× высоко (в РФ при ставках 14–20% критичнее) |
| **Interest Coverage (ICR)** | EBIT / Процентные расходы (или EBITDA / %) | > 3–5× хорошо; < 1,5× тревожно |
| **Debt / Equity** | Долг / Собственный капитал | Зависит от отрасли |
| **Debt / Capital** | D / (D + E) | Для WACC |
| **DSCR** | (EBITDA − налоги − CAPEX) / (Проценты + Погашения) | Проектное финансирование: > 1,2–1,3× |

**Ковенанты** — условия в кредитных договорах и облигациях (например, ND/EBITDA ≤ 3,0×). Нарушение даёт кредитору право потребовать досрочное погашение.

## Ликвидность

```f
Текущая ликвидность (Current ratio) = Оборотные активы / Краткосрочные обязательства     (~1,5–2)
Быстрая ликвидность (Quick ratio)   = (Оборотные активы − Запасы) / Краткоср. обязательства  (~1)
Абсолютная ликвидность              = Денежные средства / Краткоср. обязательства
```

## Оборачиваемость

```f
DSO (дни дебиторки)  = Дебиторка / Выручка × 365
DIO (дни запасов)    = Запасы / Себестоимость × 365
DPO (дни кредиторки) = Кредиторка / Себестоимость × 365
CCC (денежный цикл)  = DSO + DIO − DPO
Оборачиваемость активов = Выручка / Активы
```
X5 и Магнит в РФ, Walmart в США работают с **отрицательным** оборотным капиталом: платят поставщикам позже, чем получают деньги от покупателей.

## Для акционеров

```f
EPS = (Чистая прибыль − Дивиденды по префам) / Средневзв. число акций
DPS = Дивиденды / Число акций
Payout ratio = Дивиденды / Чистая прибыль
Дивидендная доходность = DPS / Цена
Total Shareholder Return (TSR) = (P₁ − P₀ + DPS) / P₀
```

## Банки

| KPI | Формула | Ориентир |
|---|---|---|
| **NIM** | Чистый процентный доход / Средние процентные активы | 4–6% в РФ |
| **CIR** | Операционные расходы / Операционные доходы | < 40% отлично |
| **CoR** | Резервы за период / Средний кредитный портфель | 1–2% нормально |
| **NPL** | Проблемные кредиты (90+ дней) / Портфель | |
| **Н1.0 / CET1** | Капитал / Активы, взвешенные по риску | Регуляторные минимумы плюс надбавки |

## Проверь себя

**1. Чем ROE отличается от ROIC и какой из них показывает, создаёт ли бизнес стоимость?**
ROE = чистая прибыль / собственный капитал — доходность акционеров, она растёт от долга. ROIC = NOPAT / инвестированный капитал — доходность бизнеса на весь вложенный капитал независимо от структуры финансирования. Стоимость создаётся, когда ROIC > WACC.

**2. Что показывает формула DuPont?**
Она раскладывает ROE на три множителя: чистая маржа × оборачиваемость активов × финансовый рычаг. Так видно, откуда высокий ROE: от маржи (люкс), оборачиваемости (ритейл) или долга (банки).

**3. Что такое ковенант и что будет при его нарушении?**
Условие в кредитном договоре или облигации, например ND/EBITDA ≤ 3,0×. При нарушении кредитор получает право потребовать досрочное погашение, поэтому компании следят за запасом до ковенанта.

**4. Чистая прибыль 50, выручка 500, активы 400, собственный капитал 200. Разложи ROE по DuPont.**
Маржа = 50 / 500 = 10%; оборачиваемость = 500 / 400 = 1,25; рычаг = 400 / 200 = 2,0. ROE = 10% × 1,25 × 2,0 = 25% (проверка: 50 / 200 = 25%). Половина ROE обеспечена долгом: без рычага было бы 12,5%.

**5. Долг 300, деньги 60, EBITDA 120, EBIT 90, процентные расходы 30. Посчитай ND/EBITDA и ICR. Какой максимальный чистый долг допускает ковенант 3,0×?**
ND/EBITDA = (300 − 60) / 120 = 2,0× (умеренно). ICR = 90 / 30 = 3,0× (нижняя граница «хорошо»). По ковенанту 3,0× максимальный чистый долг = 3,0 × 120 = 360, то есть запас 120.

**6. Оборотные активы 500, из них запасы 200; краткосрочные обязательства 300. Найди текущую и быструю ликвидность.**
Текущая = 500 / 300 ≈ 1,67 (в норме 1,5–2). Быстрая = (500 − 200) / 300 = 1,0 (около нормы ~1).

**7. Выручка 1 200, себестоимость 900, дебиторка 100, запасы 150, кредиторка 120. Посчитай цикл денежных средств.**
DSO = 100 / 1 200 × 365 ≈ 30,4 дня; DIO = 150 / 900 × 365 ≈ 60,8 дня; DPO = 120 / 900 × 365 ≈ 48,7 дня. CCC = 30,4 + 60,8 − 48,7 ≈ 42,6 дня — столько деньги компании «заморожены» в обороте.

**8. Акцию купили за 100 ₽, через год она стоит 110 ₽, получен дивиденд 8 ₽. Каков TSR?**
TSR = (110 − 100 + 8) / 100 = 18%: 10% рост цены плюс 8% дивидендной доходности.

**9. Как спросят на собеседовании: «У компании ROE 30%. Это хорошо?»**
Не обязательно. Через DuPont надо понять источник: если ROE высокий из-за большого рычага (активы/капитал), то риск выше, а при отрицательном или маленьком капитале ROE вообще неинформативен. Смотрю ROIC против WACC, долговую нагрузку (ND/EBITDA, ICR) и сравниваю с аналогами.

**10. Как спросят на собеседовании: «Почему X5 или Walmart могут работать с отрицательным оборотным капиталом и хорошо ли это?»**
Покупатели платят сразу, запасы оборачиваются быстро, а поставщикам ритейлер платит позже (DPO > DSO + DIO). Получается, что поставщики бесплатно финансируют бизнес; при росте выручки такой ритейлер даже высвобождает деньги. Это признак переговорной силы, но если рост остановится или поставщики сократят отсрочку, денег станет меньше.
