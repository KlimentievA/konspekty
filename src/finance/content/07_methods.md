# Другие методы оценки
short: DDM, EVA, RI, NAV, SOTP, затратный, реальные опционы

> **Суть.** Три большие группы подходов: **доходный** (DCF, DDM, EVA, RI: стоимость из будущих доходов), **сравнительный** (мультипликаторы, сделки) и **затратный** (сколько стоят активы). В российской оценочной практике (ФСО) эти три подхода называются так же.

## Модель дисконтирования дивидендов (DDM)

```f
P₀ = Σ DPSₜ / (1 + Ke)^t
Модель Гордона:  P₀ = DPS₁ / (Ke − g)
g = ROE × (1 − Payout)       — устойчивый рост за счёт реинвестиций
```

**Где применять:** банки, страховые, коммунальные компании, стабильные дивидендные истории (в РФ: Сбер, МТС, Транснефть, генерация).
**Пример:** Сбер, дивиденд за 2025 год 37,64 ₽. Если Ke = 22%, g = 6%: P = 37,64 × 1,06 / (0,22 − 0,06) ≈ **249 ₽** (иллюстрация, а не рекомендация; при цене около 287 ₽ рынок закладывает меньший Ke или больший g).

Многостадийная DDM: высокий рост несколько лет → стабильный рост (Гордон в конце).

## EVA (Economic Value Added, экономическая добавленная стоимость)

Методика Stern Stewart. Компания создаёт стоимость, только если зарабатывает **больше**, чем стоит её капитал.

```f
EVA = NOPAT − WACC × Инвестированный капитал
    = (ROIC − WACC) × Инвестированный капитал
NOPAT = EBIT × (1 − t)
Инвестированный капитал (IC) = Собств. капитал + Чистый долг   (= NWC + Основные средства + НМА)
ROIC = NOPAT / IC
```

**MVA (Market Value Added)**, рыночная добавленная стоимость:
```f
MVA = Рыночная стоимость капитала − Инвестированный капитал = Σ PV(будущих EVA)
Стоимость компании = IC₀ + Σ EVAₜ / (1 + WACC)^t
```
Корректно сделанная EVA-оценка **даёт тот же результат, что DCF**: это просто другая раскладка тех же денег.

**Зачем:** оценка эффективности менеджмента и подразделений, бонусы привязывают к EVA.

**Почему EVA не подходит банкам:** у банка нельзя разумно определить «инвестированный капитал» и WACC: долг является операционным ресурсом. Для банков используют аналог: **RI (residual income) на собственный капитал** или **RAROC**.

## Модель остаточной прибыли (Residual Income, RI, модель Эдвардса–Белла–Ольсона)

Аналог EVA, но на уровне **акционеров**:
```f
RIₜ = Чистая прибыльₜ − Ke × Собств. капиталₜ₋₁ = (ROE − Ke) × BVₜ₋₁
Equity Value = BV₀ + Σ RIₜ / (1 + Ke)^t
```
**Где:** **банки и страховые** (балансовая стоимость у них близка к рыночной, большая часть стоимости в капитале), компании без дивидендов.

## NAV (Net Asset Value, стоимость чистых активов)

```f
NAV = Рыночная стоимость активов − Обязательства
```
**Где:** недвижимость и REIT (активы переоценены по рынку), инвестиционные холдинги (АФК «Система»), фонды, добыча (NAV = сумма DCF по каждому месторождению или руднику), ликвидация.
Холдинги часто торгуются с **дисконтом к NAV** (20–50%): двойные издержки, корпоративное управление, неликвидность.

## SOTP (Sum of the Parts, оценка по частям)

Каждый сегмент оцениваем своим методом и мультипликатором, затем складываем:
```f
EV = Σ EVсегмента − Корпоративные расходы (капитализированные) ;  Equity = EV − Чистый долг ...
```
**Где:** конгломераты (Яндекс: поиск, такси, e-com, финтех), холдинги, нефтяники (добыча + переработка).

## Затратный подход

- **Балансовая стоимость** (book value).
- **Скорректированные чистые активы**: переоценка каждого актива по рынку.
- **Стоимость замещения**: сколько стоит построить такой же бизнес с нуля. Отсюда **Q Тобина** = рыночная стоимость / стоимость замещения.
- **Ликвидационная стоимость**: активы при быстрой продаже минус обязательства. Нижняя граница стоимости, нужна при банкротстве и реструктуризации.

## Реальные опционы

Право (но не обязанность) расширить проект, отложить его или закрыть. Оценка через модель Блэка–Шоулза или биномиальное дерево. **Где:** биотех (этапы клинических испытаний), разведка месторождений, R&D, стартапы.

## Стартапы и венчур

У стартапа нет прибыли и истории, поэтому DCF с одной ставкой не работает:
- **Метод венчурного капитала (VC method):**
```f
Post-money = Exit value / (Целевой мультипликатор возврата, например 10×)
Pre-money  = Post-money − Инвестиции
Доля инвестора = Инвестиции / Post-money
```
- Мультипликаторы раундов (EV/ARR, EV/GMV), метод Беркуса, scorecard, First Chicago (взвешенные сценарии).

## Сводка подходов: «футбольное поле» (football field)

В питчбуке результаты всех методов показывают горизонтальными полосами диапазонов (DCF, comps, сделки, 52-недельный диапазон цены, целевые цены аналитиков). Пересечение полос — разумный диапазон цены.
