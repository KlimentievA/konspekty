# Формат урока (проверка: `python3 src/english/parse_lesson.py src/english/lessons/NN_slug.md`)

Эталон — `lessons/01_znakomstvo-to-be.md`. Структура: заголовок `# Урок N. Название` + строки short/level/unit/theme/minutes, затем разделы `##` ровно в таком порядке и с такими названиями:
Цели · Теория · Слова · Диалог · Упражнения · Вместе · Запомни · Мини-тест.

- **Цели** — 3–8 пунктов `- …`.
- **Теория** — ≥ 700 слов, ≥ 3 подраздела `### …`, обычный markdown: таблицы, списки, цитаты `> **Запомни.** …`, ❌/✅ для ошибок.
- **Слова** — таблица из 4 столбцов `| English | Перевод | Пример | Перевод примера |`, 20–32 слова, без повторов.
- **Диалог** — строка с названием в `**…**`, затем ≥ 10 реплик `- Имя: English | русский перевод`.
- **Упражнения** — ≥ 5 наборов `### Упражнение N. Название`, под заголовком одна строка инструкции, затем нумерованные пункты (5–12 на набор, всего ≥ 40):
  - ввод: `1. She ___ to school. => goes` (один пропуск `___`; или предложение для перевода без пропуска; несколько допустимых ответов — через ` / `)
  - выбор: `1. She ___ to school. :: go | goes* | going` (звёздочка у верного, 3–4 варианта)
  - пояснение к пункту (по желанию): следующей строкой `// …`
  - в наборах должны быть оба типа (ввод и выбор) среди всех наборов урока.
- **Вместе** — ≥ 200 знаков: 3 задания для двоих (ролевые диалоги, игры, вопросы друг другу).
- **Запомни** — ≥ 5 пунктов `- …`.
- **Мини-тест** — ровно 10 пунктов с выбором (`::`).
Символы `|` и `=>` / `::` внутри самого текста пунктов не использовать.

# Формат справочной страницы (ref/NN_slug.md)
Первая строка `# Название`, вторая `short: одна строка описания`, дальше обычный markdown (## подразделы, таблицы, списки, цитаты `> **Запомни.** …`). Объяснения на русском, примеры на английском с переводом. Проверка: `python3 src/english/parse_lesson.py src/english/ref/NN_slug.md`.
